## 🏛️ About Antaara Design Studio
Antaara Design Studio is a premier interior architecture studio founded by **Kirti Jaiswal Rajpal**. With over a decade of craftsmanship, the studio creates bespoke, timeless living and commercial environments that harmoniously balance spatial poetry, natural light, tactile materiality, and everyday human living.

---

## ✨ Key Features
- **Cinematic Experience**: 3D spatial project showcase with dynamic mouse physics, interactive day/night lighting simulation, and real-time IST Indore clock.
- **Authentic Architectural Archive**: 19+ curated commissions spanning Indore, Mathura, and Kolkata, featuring projects like Coffee by Di Bella, Hotel Pride Cottages, and BCM Planet Luxury Residences.
- **Editorial Typography**: Refined modern luxury typography powered by Outfit, Plus Jakarta Sans, and Cormorant Garamond.
- **Interactive Lead Capture & Admin Portal**: Project management, inquiry status tracking, and commissioning workflows.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm run start
```
